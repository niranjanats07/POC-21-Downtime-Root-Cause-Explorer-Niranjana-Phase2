# Downtime Root Cause Explorer

**Infocreon Internship – PoC 21 | Phase 2**

An interactive dashboard for analysing downtime incidents, root causes, machines and shifts.

## Project Overview

This project helps users explore synthetic downtime incident data through interactive charts, KPIs, filters and incident investigation panels.

## Technology Stack

- Frontend: Next.js, React, TypeScript
- Backend: Python, FastAPI
- Data: Synthetic CSV dataset
- Containerization: Docker and Docker Compose (Phase 2)

## Phase 2 Objective

Containerize the existing application and validate frontend-to-backend communication in a reproducible local environment.
